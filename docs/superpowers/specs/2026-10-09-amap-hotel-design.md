# 高德酒店地点搜索

用户已确认修改本目录的命令行 hotel_search，使用高德 Web 服务 Key。
本仓库没有 openspec 目录，不初始化 OpenSpec；本文件记录已确认的接入设计。

## 行为

- 从后端 .env 的 AMAP_API_KEY 读取密钥，绝不写入结果、来源 URL 或错误信息。
- 高德酒店搜索只必填 city，keywords 可选，默认“酒店”；入住日期、人数可携带，但不作为地点搜索必要条件，也不代表查过库存。
- 调用 /v5/place/text，限定住宿类别、城市，取最多 25 个地点候选，沿用本地候选窗口（默认 5 个）、品牌偏好排序、缓存和刷新。
- 返回高德地点 ID、名称、地址、城市、区县、经纬度及可用电话、评分、图片；保留来源和取得时间。
- 酒店地点与酒店房型报价是不同的数据类型。地点没有房型、价格或库存证据，固定保留未知；不把 business.cost 当成房价。
- 地点候选可展示、可被行程选择，但不计入已知费用。存在预算/空房硬条件时保留为未验证的地点参考，明确说明不能证明满足条件，结果标为 partial。
- 保持已注入的 HotelOffer 报价 Provider 行为和旧测试兼容，火车和攻略业务不改。
- 无 Key 返回 unavailable；高德业务错误、网络或响应异常返回安全失败；真正空结果返回成功空列表。

## 技术

独立 hotel_places.py 定义地点查询/候选和本地视图，amap_hotel.py 负责网络与归一化。
ToolExecutor 根据 Provider 的地点能力选择查询契约和 schema；旧报价 Provider 仍要求入住区间/人数。
结果和行程校验仅增加地点类型分支；预算仅接收原报价对象；CLI 注册高德 Provider，并正确展示候选。
共享文件用小块补丁追加，保留另一窗口的攻略修改，不重置或覆盖文件。
