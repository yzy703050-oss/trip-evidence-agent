# v1：原生工具混合编排

v1 是现有 trip-evidence-agent 的增量重构，保留多段差旅、政策、偏好、SQLite 与历史恢复。

## v0 保存位置

原 GitHub 主线已保存为 [v0 分支](https://github.com/yzy703050-oss/trip-evidence-agent/tree/v0)，提交为 d017f6ba9c6e587ffa5bcd7f041b75962f129dd9。v1 使用独立 PR 分支 codex/v1-native-agent-readme，创建 PR 不修改 v0，也不会自动合并 main。

## 主要变化

- run_turn 取代旧顶层 Runner，使用原生 tool_calls 批量预检和执行。
- Main 一次提出完整初案；工具后 Summary/Verifier 比较候选、选择或局部修复，必要时交回 Main。
- TripQueryExecutor 根据待查项执行查询，与独立查询复用有效证据。
- 运行状态、执行任务与 TripPlan 业务状态分开；恢复基于回执，不重放已完成写入。
- 硬条件快照、候选归属、版本检查、依赖失效及原子提交由程序维护。
- 最终事实通过 reply 绑定同次保存回执，活动变化必须实际 amend。
- 暂停原生攻略查询和默认攻略注册，保留旧组件与历史数据。

## 兼容与限制

旧文件保留非破坏迁移，SQLite 为权威存储。旧内部 Python 导入路径不作为兼容 API，部分数据字段保留 workflow 等旧名称。整轮单次实验仅显式回放，不作为产品默认。

当前为 CLI 铁路差旅及酒店地点规划，不执行预订支付，也不保证房价房态。最新真实模型加模拟供应商十例，按当前验收口径人工10/10；附带辅助活动不作为不通过项，此次为已有结果复核，未重新运行模型。参数纠错等细节暂留后续迭代。[评测摘要](../evals/v1/assessment.md)

发布不包含本地.env、用户数据库、本地模型、知识库索引、运行会话或原始供应商/模型响应。演示使用脱敏的模拟供应商评测输出，明确说明数据性质。

本次PR仅新增运行源码、必要测试、配置示例和公开材料；不新增本地内部实施记录、OpenSpec变更档案或企业政策正文。仓库原有公开资料保留。
