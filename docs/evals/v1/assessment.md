# v1 公开评测摘要

本摘要来自2026-10-19暂停攻略查询后的同条件真实模型评测，只发布汇总，不包含用户数据库、运行会话、模型完整输入或原始供应商响应。

## 测试条件

- 真实模型：deepseek-flash，temperature=0.3，thinking disabled，最多8轮。
- 高铁、酒店及政策均为模拟；高铁重庆↔上海暂设420分钟，不代表真实时刻或可购买资源。
- 请求时间固定为2026-10-19T17:40:36.664442+08:00，常规活动为请求后两天。
- 旅游、政策可用、政策缺失、混合酒店查询、已有活动修改五类各两例。先测两例原失败旅游，再补其余八例，没有重跑最好样本或额外评判模型。

## 已知限制

一例混合旅游请求新增了“退房返程”辅助活动，自动检查通过但人工未通过；另有部分活动描述跨时段、一次车种强度参数纠错和三例提前独立查去程。用户已同意这些细节暂留后续，不因运行正常声称规划全部合理。

需求字段检查覆盖55/56；其中一项因task未显式填departure_date（使用start_date及查询日期）未计入，但实际车次仍为用户要求的出发日。指标定义保留，不用更改规则抬高分数。

样本量小，结果不等同线上成功率。模拟政策不包含生产检索/解析开销；真实供应商的延迟、可用性和价格需另行评测。未配置费用单价，不将未知金额写成零。
